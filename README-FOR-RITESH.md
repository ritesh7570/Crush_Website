# How to finish and host this

## 1. Add music (2 min)
Put an mp3 file inside the `music/` folder and name it exactly:
    music/bg-music.mp3
Pick something you already have the right to use — a bhajan you own, or a
royalty-free track (search "royalty free Shiva instrumental" on Pixabay
Music or YouTube Audio Library — both are free to download and use).
No file = the page still works, the sound button just won't play anything.

## 2. Put it on GitHub Pages (5 min)
1. Create a new repo on GitHub (e.g. `for-roshani`).
2. Upload these 5 files/folders into it: index.html, style.css, script.js, 
   music/ (with your mp3 inside).
3. Go to repo Settings → Pages → under "Branch" pick `main` and `/ (root)` → Save.
4. Wait ~1 minute, then your link will be:
   https://<your-github-username>.github.io/for-roshani/

## 3. Send it
Send the link directly — it works great on mobile, which is probably how
she'll open it.

## If you want to change the wording
Open index.html in any text editor. The two most personal blocks are inside
`<section class="note">` and `<section class="closing">` — edit the text
between the `<p>` tags freely, everything else can stay as is.
